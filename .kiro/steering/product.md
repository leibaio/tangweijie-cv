# Product Overview

This is a personal portfolio website and CV generator for Tang Weijie (汤伟杰). The site features:

- Online resume/CV with multiple visual styles
- Technical blog with markdown support
- Project showcase section
- Bilingual support (Chinese/English)
- Multiple theme options (light/dark mode, color themes)
- Three distinct home page styles: Tech, Minimal, and Terminal

The site serves as both a professional portfolio and a platform for sharing technical content, with a focus on full-stack web development.
