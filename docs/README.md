## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3000
```

## 项目亮点

✨ **现代技术栈**：Next.js 15 + React 19 + TypeScript 5  
🎨 **多风格主题**：科技风/极简风/终端风三种首页风格  
🌍 **国际化**：完整的中英文双语支持  
🎭 **主题系统**：深色/浅色模式 + 多种颜色主题  
📱 **响应式设计**：完美适配桌面和移动设备  
🖨️ **打印优化**：简历页面可直接打印导出
