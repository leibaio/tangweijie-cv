项目背景Context

海外小说阅读官网，流量主要来自 Google 自然搜索。站点既要被搜索引擎完整收录，也要在移动端提供顺畅的阅读体验，并引导读者下载客户端。 An overseas novel site with traffic mainly from organic Google search. It must be fully crawlable, comfortable to read on mobile, and guide readers into the app.

关键设计Key decisions

  • SEO 是主路径：SSR / 预渲染和结构化数据优先于花哨交互。SEO is the primary path: SSR / prerender and structured data come before flashy interactions.
  • 书籍页与阅读器共用同一份书籍 / 章节数据，减少重复请求和状态分叉。Book pages and the reader share the same book / chapter data, reducing duplicate requests and divergent state.
  • 移动端用 rem 等比适配，PC / Mobile 各自布局，而不是简单缩放。Mobile uses rem-based proportional scaling, with separate PC / Mobile layouts rather than simple scaling.

我做了什么What I built

  • Nuxt3 SSR + `nuxt build --prerender`：首屏直出 HTML，解决 SPA 内容不被搜索引擎索引的问题。Nuxt3 SSR + `nuxt build --prerender`: real HTML on first paint, solving SPA content not being indexed by search engines.
  • 结构化数据：站点级 WebSite；书籍详情与章节页注入 Book + aggregateRating；配合语义化标签与动态 sitemap 提升索引质量。Structured data: WebSite at the site level; Book + aggregateRating on book and chapter pages; semantic markup and a dynamic sitemap for better indexing.
  • 响应式：postcss-pxtorem rootValue 75 + flexible，PC / 移动端不同布局与交互。Responsive: postcss-pxtorem at rootValue 75 + flexible, with distinct PC / mobile layouts and interactions.
  • 阅读器体验：章节切换、目录、上一章 / 下一章、字号与排序、客户端深链唤起。Reader experience: chapter switching, table of contents, previous / next, font size and sorting, plus client deep-link launch.
  • 埋点与下载转化：usage_record 记录 Ranking / Category / 详情 / 下载来源；应用商店下载弹窗。Analytics and download conversion: usage_record tracks Ranking / Category / detail / download source; app-store download modal.
