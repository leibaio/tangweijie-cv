Architecture · ttigd 运营配置台

前后端总体架构：配置后台 + AI 分析旁路

Vue 3 运营台 → Nginx → Spring Boot 配置后台 / AI BFF → MySQL / Redis / OSS / 游戏服 / LLM

FRONTEND

Vue 3 运营台

  • Vue 3.5 + Vite 5 + TypeScript + TDesign
  • Pinia 状态、动态路由、roleCode 权限
  • 8 个路由模块、230+ 页面组件
  • AI 分析页走 /bff-api + SSE，不走 Axios
  • Axios 统一封装：code=0 成功、8001 登录过期

BACKEND

Spring Boot 配置后台

  • Spring Boot 2.7.3 / JDK 11 / Gradle 多模块
  • Shiro + shiro-redis 负责登录与会话
  • MyBatis-Plus 双 MySQL 数据源
  • 39 个 Controller 包 / 163 个 Controller 类
  • AI 分析：/v1/aiAnalysis/**（BFF 回调）

INTEGRATION

下游与集成

  • Redis pub/sub：配置热更广播
  • OSS：version.json / module.md5 下发给客户端
  • game-backend：40+ Retrofit HTTP 接口
  • AI BFF：LLM 流式分析 + ThinkingData
  • 微信 / 抖音 / AliBI / 邮件 / 短信
