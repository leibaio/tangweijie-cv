ER · Config Domain

配置数据模型：发布域的核心表与逻辑引用

fun_ab_config 是聚合根；功能类型、渠道、版本号、发布账本与同步注册围绕它展开

AGGREGATE

功能开关配置

  • fun_ab_config：名称、分组、版本、状态
  • open/close_channel_config_ids 存 CSV
  • publish_status：0 未发 / 1 成功 / 9 失败
  • del_flag 逻辑删除，发布时过滤

LOOKUP

三张映射表

  • base_fun_type_info：name → type 编码
  • base_channel_type_info：渠道 code / type
  • base_system_config_info：game_version
  • 版本号是字符串，不在配置表建外键

LEDGER

发布与同步

  • quick_publish_info：模块 → 版本列表
  • app_config_info：客户端配置 + 发布状态
  • syn_table_info：体验服 → 正式服同步注册
  • 均按 module/name 逻辑关联，无物理外键
