Deployment · ttigd-manage

部署视图：一个 JVM、一套数据层、多环境路由

Nginx 托管前端静态资源并反代 /ttigd-manage；Spring Boot 独立进程连接 MySQL、Redis、OSS 与 MongoDB

RUNTIME

进程与启动

  • 独立 Spring Boot 进程，context-path /ttigd-manage/
  • JDK 11，启动加 --add-opens java.base/java.lang.invoke
  • Actuator / Prometheus 暴露在 /endpoints
  • Swagger UI：/swagger-ui/index.html

ENVIRONMENT

环境与路由

  • test / inner：/html8/ + test domain
  • pre：/ + staging domain
  • prod：/ + prod domain
  • 前端 /ttigd-manage 由 Nginx 反代

DEPENDENCIES

数据与外部服务

  • MySQL：配置库 + 生产只读库双数据源
  • Redis：Shiro 会话 + 配置热更广播
  • OSS：私有 / 公开 / 分享三个 bucket
  • MongoDB：config-compare 直连
