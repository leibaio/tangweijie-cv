Sequence · Auth & Permission

前端请求与权限时序：登录、取权限、动态挂路由

登录走 Shiro Session（Redis），/login-info 返回 privileges，前端按 roleCode 过滤本地路由树

LOGIN

登录与会话

  • POST /login，multipart 表单
  • 短信验证码由 SmsService 校验
  • Shiro 把会话写入 Redis
  • 浏览器持有 gd_sessionId Cookie

ROUTING

权限与动态路由

  • /login-info 返回用户与 privileges
  • 路由树是前端本地定义，不发请求
  • 按 meta.roleCode 过滤后 addRoute
  • 无权限路由不会注册到 router

REQUEST

业务请求

  • 携带 Cookie 与 Authorization 头
  • 后端以 Shiro Session 为准
  • code=0 返回 data
  • code=8001 清状态并跳 /login
