Layer Stack · ttigd-manage

后端工程分层：一个可启动入口，五层依赖

Gradle 多模块项目，上层依赖下层；只有 ttigd-manage-web 打包为可执行 Spring Boot Jar

BUILD

Gradle 多模块

  • settings.gradle 声明 6 个子模块
  • 统一 Java 11 与 Spring Boot 2.7.3 BOM
  • 仅 ttigd-manage-web 启用 bootJar
  • 部署需 --add-opens java.base/java.lang.invoke

RESPONSIBILITY

各层职责

  • web：REST 入口、Shiro、Swagger、全局异常
  • service：业务编排、QuickPublish、定时任务、Retrofit
  • dal：MyBatis-Plus Mapper 与两套 MySQL
  • model / util / poker-common：契约、枚举工具、牌库算法

BOUNDARY

依赖边界

  • web → service → dal → model
  • service 可引用 poker-common
  • dal 不感知 Controller
  • 新增模块需在 settings.gradle 注册
