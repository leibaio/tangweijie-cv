Architecture · AI BFF

AI 分析 BFF：从运营页面到 LLM 的流式链路

Vue AI 分析页 → Nginx /bff-api → Node/Hono BFF → Java 数据接口 + LLM + ThinkingData → SSE 回浏览器

BFF ROLE

无状态中间层

  • Node.js + Hono，PM2 托管
  • 不连数据库；持久化全部回调 Java
  • 组装 prompt、限流、TA 熔断
  • API Key 与模型地址只存在服务端 .env

DOWNSTREAMS

三条下游

  • Java：/v1/aiAnalysis 报表、日志、评论、对话
  • LLM：chatOnce 摘要 + streamChat 深度分析
  • ThinkingData：DAU / 收入 / 对局 / 场次
  • LLM 兼容 OpenAI 协议，可切供应商

STREAM

流式链路

  • 前端 fetch + ReadableStream 消费 SSE
  • 消息：chunk / done / error / action
  • Nginx 关闭 buffering，读超时 120s
  • 分析中按 reportId 防并发
