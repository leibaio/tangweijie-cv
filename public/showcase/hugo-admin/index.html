项目背景Context

一个角色众多的内部运营后台，同一套页面要服务编辑、BD、法务、财务、运营等不同权限；合同、税表和结算又横跨多个业务模块，状态流转复杂。 A multi-role internal back office where the same pages serve editors, BD, legal, finance and operations; contracts, tax and settlement cut across modules with complex state transitions.

关键设计Key decisions

  • 权限按角色过滤路由树，菜单和页面访问同源，避免前后端两套规则。Permissions filter the route tree; menu and page access share one source, avoiding two rule sets across frontend and backend.
  • 合同、税表、结算共用一套状态模型，减少跨模块重复。Contracts, tax and settlement share one status model, reducing duplication across modules.
  • Vite 迁移优先保证构建速度和 HMR，再逐步替换旧 webpack 配置。The Vite migration prioritized build speed and HMR, then replaced legacy webpack configuration incrementally.

我做了什么What I built

  • 多角色动态路由：按 authority 过滤路由树，覆盖 admin / 编辑 / BD / 法务 / 财务 / 运营等角色。Role-based dynamic routing: the route tree is filtered by authority for admin, editor, BD, legal, finance and operations roles.
  • 合同与结算：合同审核、电子签、W-8 / W-9 税表审核、书籍 / 大纲结算、付款状态流转。Contracts and settlement: contract review, e-signature, W-8 / W-9 tax review, book / outline settlement and payment status transitions.
  • 内容生产链路：作品上传 / 分章、章节审查、大纲库、试读、机翻 / 敏感词 / 相似标题工具。Content pipeline: book upload / chapters, chapter review, outline library, trial reads, translation / sensitive-word / similar-title tools.
  • 数据与投放：书籍测试汇总、In-App 表现、作者付款看板、广告 Campaign 管理、Excel 导出。Data and acquisition: book-testing summary, In-App performance, author payment dashboard, ad campaign management and Excel export.
  • 工程化：参与构建体系从 vue-cli / Webpack 迁移到 Vite，路由级代码分割、SVG 雪碧图与公共组件沉淀。Engineering: contributed to the vue-cli / Webpack → Vite migration, route-level code splitting, SVG sprites and shared components.
